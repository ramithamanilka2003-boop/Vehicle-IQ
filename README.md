# Vehicle-IQ
VehicleIQ is a machine learning-based web application that predicts the prices of used vehicles based on various features such as brand, model, year, mileage, and fuel type. The system is built using the Flask framework for the backend and integrates a trained regression model to generate accurate price estimations.

Users can input vehicle details through a web interface, and the system processes the data to provide a predicted market price in real time. This helps buyers and sellers make informed decisions by analyzing historical data and trends.
